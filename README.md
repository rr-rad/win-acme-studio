# 🛡️ WIN ACME Wildcard SSL Studio

یک پنل تحت وب فوق‌العاده حرفه‌ای، با طراحی دارک و انیمیشنی برای مدیریت و صدور گواهینامه‌های **Wildcard SSL (`*.domain.com`)** رایگان از مرجع رسمی **Let's Encrypt** بر روی سیستم‌عامل ویندوز، با استفاده از اسکریپت محبوب `acme.sh` و محیط محلی XAMPP.

این پروژه مشکل بزرگ اجرای اسکریپت‌های لینوکسی شل (`.sh`) را در محیط ویندوز از طریق سوییچ هوشمند به `Git Bash` حل می‌کند و پروسه دو مرحله‌ای احراز هویت دستی دی‌ان‌اس (DNS-01 Challenge) را به راحت‌ترین شکل ممکن به یک رابط کاربری وب تبدیل می‌سازد.

---

## ✨ ویژگی‌های کلیدی (Features)

*   **🎨 تم مدرن سایبرپانک:** طراحی واکنش‌گرا و انیمیشنی با استفاده از Tailwind CSS و FontAwesome.
*   **🌐 پشتیبانی کامل از Wildcard:** درخواست همزمان گواهی برای دامنه اصلی (`domain.com`) و تمام زیردامنه‌ها (`*.domain.com`).
*   **🔒 اجبار به استفاده از Let's Encrypt:** دور زدن ZeroSSL (که مرجع پیش‌فرض جدید acme.sh است) و هماهنگی کامل با سرورهای لتس‌انکریپت.
*   **⚙️ حل چالش سرویس ویندوز (XAMPP Service Fix):** اسکن و شناسایی هوشمند مسیر فایل‌ها در صورتی که آپاچی به صورت یک سرویس سیستمی (SYSTEM user) اجرا شود و فایل‌ها را در پوشه `System32` ذخیره کند.
*   **💻 کنسول لاگ خام:** امکان مشاهده خروجی مستقیم و زنده ترمینال در پایین صفحه برای عیب‌یابی سریع.
*   **📋 کپی با یک کلیک:** باکس‌های تفکیک‌شده و آماده برای کپی کردن سریع Private Key، Certificate و Full Chain.

## 📋 پیش‌نیازها (Prerequisites)

برای اجرای بدون نقص این پنل، باید مراحل زیر را روی ویندوز خود آماده داشته باشید:

### ۱. نصب Git برای ویندوز
از آنجا که `acme.sh` یک اسکریپت شل (`.sh`) لینوکسی است، برای اجرا در ویندوز به پایانه `Git Bash` نیاز دارد.
*   آخرین نسخه Git را از [وب‌سایت رسمی گیت](https://git-scm.com/download/win) دانلود و نصب کنید.
*   مسیر نصب پیش‌فرض باید `C:\Program Files\Git\bin\bash.exe` باشد. (اگر مسیر گیت شما متفاوت است، خط ۶ فایل `ssl.php` را تغییر دهید).

### ۲. نصب acme.sh از طریق Git Bash
۱. پایانه **Git Bash** را در ویندوز باز کنید.
۲. دستور زیر را برای کلون و نصب `acme.sh` در پوشه کاربری خود اجرا کنید (ایمیل خود را جایگزین کنید):
```bash
   git clone [https://github.com/acmesh-official/acme.sh.git](https://github.com/acmesh-official/acme.sh.git)
   cd ./acme.sh
   ./acme.sh --install -m myemail@example.com
